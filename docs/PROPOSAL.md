# Commercial Proposal & Project Roadmap
**Project:** Care4uuu Platform MVP
**Prepared By:** Growth Hikes

---

## 1. Project Overview
Growth Hikes proposes to develop the Minimum Viable Product (MVP) for "Care4uuu," a comprehensive on-demand healthcare platform. This proposal outlines the commercial terms, resource allocation, and delivery roadmap.

## 2. Resource Allocation
To ensure rapid delivery and high-quality execution, Growth Hikes has secured the following dedicated resources for this engagement:

*   **Sahil Rathee - Lead Developer (Full Stack):** Responsible for system architecture, mobile application development (Flutter), and overall technical delivery.
*   **Jitender Bachhraj - Backend Developer:** Responsible for the Go microservices architecture, database management, and cloud infrastructure.

## 3. Commercial Terms
Growth Hikes is pleased to offer a fixed-cost engagement model for the documented scope.

*   **Total Project Cost:** **₹3,00,000 INR** (Three Lakhs Indian Rupees).
*   **Engagement Model:** Fixed Cost, Milestone-Based.
*   **Duration:** 12 Weeks.

### Value Proposition
*   **Dual Native Apps:** High-performance mobile applications built on Flutter for both iOS and Android.
*   **Microservices Architecture:** A backend built on Golang to ensure future scalability comparable to enterprise platforms.
*   **Regulatory Compliance:** Integration of Escrow payment logic and secure data handling practices.
*   **Full IP Ownership:** Complete transfer of source code ownership upon project completion.

## 4. Payment Schedule
The payment structure is designed to align financial milestones with tangible project deliverables.

1.  **Project Initiation (30% - ₹90,000):** Covers resource reservation and initial infrastructure setup.
2.  **Design & Core Logic (30% - ₹90,000):** Due upon completion of UI/UX implementation and authentication systems (Approx. Week 4).
3.  **Beta Release (20% - ₹60,000):** Due upon delivery of the functional test build (APK/TestFlight) for User Acceptance Testing (UAT).
4.  **Go-Live (20% - ₹60,000):** Due upon final deployment to production and handover of all assets.

## 5. Proposed Timeline

| Milestone | Deliverables |
|-----------|--------------|
| **Weeks 1-2** | Solution Architecture, Database Design, Initial Setup. |
| **Weeks 3-5** | Implementation of Authentication, User Profiles, and Admin Dashboard. |
| **Weeks 6-8** | Development of Booking Engine, Calendar Management, and Wallet features. |
| **Weeks 9-10** | Integration of Chat, Notifications, and Geolocation services. |
| **Weeks 11-12** | Comprehensive QA, Security Audits, and Final Deployment. |
